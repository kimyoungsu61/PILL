# PILL 시작 화면과 대표 모션

[Figma 편집 원본](https://www.figma.com/design/v0tLh7XCFWT7KBsjuOtEoC?node-id=2-38)

PILL의 기존 캡슐 아이콘과 파란색을 이어서 만든 짧은 시작 모션입니다. 두 조각이 정렬되고 PILL 이름이 나타납니다. 제품 화면에는 로고만 표시하며, 연결이 오래 걸릴 때만 짧은 로딩 안내가 나타납니다.

## 파일

- `pill-mark.svg`: 배경이 없는 캡슐 벡터. 두 면을 개별 경로로 편집할 수 있습니다.
- `pill-lockup.svg`: 캡슐과 PILL 이름의 정적인 조합. 글자는 편집 가능한 텍스트이며 Inter 또는 시스템 글꼴을 사용합니다.
- `pill-startup.mp4`: Figma 타임라인에서 내보낸 390 × 844, 30fps 영상. 2초 타임라인 중 약 0.64초에 로고가 완성되고 마지막 상태를 유지합니다. 앱은 이 영상을 다운로드하지 않고 벡터를 직접 움직입니다.
- `motion-spec.json`: 색상, 타이밍, 원본 노드, 접근성 및 재생 규칙.

## 앱 적용

`app/src/components/BrandMark.tsx`가 벡터를 그리고, `AppStartup.tsx`가 시작 모션과 화면 전환을 담당합니다. 공통 경로와 타이밍은 `app/src/branding/brandMotion.ts`에 있습니다.

- 0–500ms: 두 조각이 60ms 후부터 정렬됩니다.
- 340–640ms: PILL 이름이 나타나며 6px 위로 이동합니다.
- 900–1080ms: 로그인 상태 확인이 끝났다면 첫 화면으로 전환합니다.
- 로그인 상태 확인은 모션과 동시에 시작합니다. 연결이 오래 걸리면 완성된 로고를 유지하고 1800ms 후 안내를 표시합니다.
- 앱을 새로 시작할 때 한 번 재생합니다. 탭 이동, 로그인, 로그아웃 때는 반복하지 않습니다.
- 기기의 ‘동작 줄이기’가 켜져 있으면 정적인 로고를 사용하며 의도적인 시작 대기 시간을 생략합니다.
- 네이티브 OS 시작 화면 설정은 변경하지 않았습니다. 이 모션은 앱이 실행된 후 재생됩니다.

Figma 화면은 Inter Semi Bold, 한국어 안내는 Noto Sans KR를 사용합니다. 앱은 기존 시스템 글꼴을 유지하므로 글자 모양에 작은 차이가 있습니다.

## 확인

타입 검사, 기존 8개 테스트와 23개 계약 검사, Expo 웹 빌드가 통과했습니다. Chrome의 아이폰 크기 화면에서 로그인 진입, 세션 만료, 느린 연결, 동작 줄이기를 확인했습니다. 미리보기는 예시 계정과 메모리 데이터를 사용했습니다. 실제 아이폰과 Railway에는 아직 반영하지 않았습니다.

Figma 영상은 실제 재생 중 0.2 / 0.4 / 0.6 / 0.8초의 프레임을 확인했습니다. 편집 원본의 캡슐과 글자는 벡터·텍스트이며 평면 이미지로 합치지 않았습니다.

앱 흐름과 모션 편집 원본은 Figma에서 관리합니다. Canva에서 소개 영상을 만들 때는 이 MP4와 SVG를 가져와 사용할 수 있습니다.
