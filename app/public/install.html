ON YOUR IPHONE

아이폰에 PILL 추가하기

한 번 추가하면 다음부터 아이콘을 눌러 열 수 있어요.

  1. 1

    Safari에서 이 페이지 열기

    친구에게 받은 링크도 Safari에서 열어 주세요.

  2. 2

    공유 버튼 누르기

    공유 버튼이 안 보이면 더 보기(···) → 공유를 눌러 주세요.

  3. 3

    ‘홈 화면에 추가’ 선택하기

    ‘웹 앱으로 열기’ 항목이 보이면 켜고, 이름을 PILL로 확인한 뒤 추가를 눌러요. ‘홈 화면에 추가’가 없으면 공유 메뉴의 동작 편집에서 추가해 주세요.

  4. 4

    홈 화면의 PILL 아이콘으로 시작하기

    아이콘을 눌러 로그인해 주세요. 처음 사용하는 분은 회원가입으로 자기 계정을 만들면 돼요.

✓

복용 알림도 받아보세요

설치한 PILL에서 설정 → 알림 설정 → 알림 켜기를 허용하고 제품별 복용 시간을 켜 주세요. 테스트 알림 보내기로 확인할 수 있어요.

아이폰 웹 알림은 iOS 16.4 이상에서 사용할 수 있어요.

안드로이드에서는 어떻게 설치하나요?

Chrome에서 이 링크를 연 뒤 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치를 선택해 주세요.
